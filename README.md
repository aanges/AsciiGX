# 🚀 AsciiGX

**AsciiGX** to zaawansowana, otwarta (Open Source) modyfikacja i przeglądarka środowiska Scratch. Naszym celem jest rozszerzenie możliwości standardowego edytora o funkcje, których brakuje społeczności, przy zachowaniu 100% kompatybilności z Twoimi projektami.

---

## ✨ Funkcje
* **Rozszerzony Edytor:** Nowe narzędzia ułatwiające programowanie.
* **Wysoka Wydajność:** Zoptymalizowane działanie projektów.
* **Pełna Kompatybilność:** Twoje pliki `.sb3` działają bez problemu.
* **Open Source:** Każdy może sprawdzić kod i pomóc w rozwoju.

## 🛠️ Jak pomóc?
Jesteśmy projektem tworzonym przez społeczność! Możesz nas wesprzeć na kilka sposobów:
1.  **Zgłaszanie błędów:** Skorzystaj z naszego forum na Discordzie o nazwie: `opinie i błędy`.
2.  **Kodowanie:** Stwórz Pull Request z poprawkami lub nowymi funkcjami.
3.  **Beta-testy:** Testuj najnowsze wersje i dziel się opinią.
